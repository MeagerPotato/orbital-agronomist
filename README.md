# Orbital Agronomist

Voice hotline that lets smallholder farmers ask what satellites see on their field, in their own language.

Farmers in the demo are fictional. Satellite and weather series are real replays of past events. Build phases, data layout, and demo scenarios are in `docs/PLAN.md`.

## Setup

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open http://localhost:3000. Fill in `.env.local` from `.env.example`. Do not commit secrets.
